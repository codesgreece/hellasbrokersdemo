# Hellas Brokers — Demo Website

Premium demo / presentation website for **Hellas Brokers Real Estate** (Σύμβουλοι Ακινήτων · Athens Property Trust).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Hardcoded demo property data (no backend, CMS, auth, or database)

## Scripts

```bash
npm run dev
npm run build
npm start
```

## Pages

- `/` — Home
- `/properties` — Property listings
- `/properties/[id]` — Property details

## Notes

This is a client presentation demo. Contact details and properties are fictional sample content.
